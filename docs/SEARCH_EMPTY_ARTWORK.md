# 검색 결과 없음 캐릭터

- 생성 도구: built-in image_gen
- 원본 참고: `app/src/main/res/drawable-nodpi/driver_cloud.webp`
- 적용 파일: `app/src/main/res/drawable-nodpi/driver_search_empty.png`
- 투명 배경을 유지하며 검색 결과가 없을 때만 정적으로 표시한다.
- 이미지와 안내 문구는 결과 영역 가운데 배치하고, 키보드로 높이가 줄면 이미지 높이를 줄인다. 이미지가 장식이므로 접근성 안내는 아래 문구로 제공한다.
